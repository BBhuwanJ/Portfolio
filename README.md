# Bhuwan Prasad Joshi Portfolio

Static academic portfolio built with plain HTML, CSS, and JavaScript.

The `CNAME` file is set to `bhuwanprasadjoshi.com.np` for GitHub Pages custom-domain publishing.

## GitHub Pages

1. Push the contents of this folder to the root of a GitHub repository.
2. In GitHub, open `Settings` > `Pages`.
3. Set the source to the branch that contains `index.html`.
4. Save and open the Pages URL after GitHub finishes publishing.

If you push the whole `Portfolio` folder inside another repository, the page will usually be available at `/Portfolio/` instead of the site root.
